# 공식 데이터 품질 점검

제주데이터허브 1313번 상세 페이지가 제공하는 **2023년 4월 10일판 CSV**와 같은 페이지가 연결하는 **서귀포시 2024년 5월 13일판 CSV**를 내려받아 둘 다 보존했다. 웹 검색기는 허브 방화벽 차단을 반환했으나 허브의 공개 상세 조회 및 첨부 다운로드를 통해 실제 파일을 확보했다. [허브 등록 정보](https://www.jejudatahub.net/data/view/data/1313) · [허브 첨부 원본](https://www.jejudatahub.net/api/file?id=4996&fileId=4086) · [서귀포시 갱신판](https://www.data.go.kr/data/15048184/fileData.do)

**허브 원본 활용.** `data/raw/jejudatahub-1313-20230410.csv`는 20,425바이트, CP949 호환, 450행 × 10열, 2012~2021년 자료다. 완전 중복 행은 0개, 빈 수치 셀은 318개다. 기준일 열을 제외한 구조는 갱신판과 같다. 허브에서 읽은 수치 2,832개를 갱신판과 대조하고 분석 데이터에 그대로 사용했다. 비어 있던 318개 셀은 갱신판에 명시된 0을 사용했다. 2022년 수치 315개를 갱신판에서 추가했다. 서로 값이 겹치는 셀에서 수치 불일치는 없었다.

| 항목 | 서귀포시 갱신판 원본 | 분석용 |
|---|---|---|
| 파일 | `data/raw/seogwipo-citrus-20240513.csv` | `data/processed/official.csv` |

| 기간 | 생산연도 2012~2022, 11개 연도 | 동일 |

| 결측·중복 | 빈 셀 0, 완전히 동일한 행 0 | 빈 셀 0, 연도·지역·재배유형 중복 0 |
| 범위 | 지표 3개, 재배유형 7개 | 수치 3,465개, 음수 0 |

**정제 내용.** 효돈동의 후행 공백 3행을 정리하고 원본의 7개 열을 재배유형 행으로 펼쳤다. 연도·읍면동·재배유형을 기준으로 생산량, 면적, 농가수를 결합했다. 두 원본의 수치 정밀도를 유지했다. 농가수에 소수 값 27개가 있어 원본 수치를 보존했다. 원본에 산출 근거가 없어 농가수의 소수점 원인은 판단할 수 없다.

**검산.** 2012년 서귀포시 집계 생산량은 456,365톤, 2022년은 404,233.37톤이다. CSV 원본과 정규화 자료를 모든 3,465개 값에 대해 대조했다. 연도별 합계와 원본·가공본 SHA-256은 `data/processed/quality.json`에서 확인할 수 있다.

**재현.** 프로젝트 루트에서 `python data/prepare_official.py`를 실행하면 보존한 원본의 SHA-256을 확인하고 표준 CSV와 품질 통계를 다시 생성한다. 제공기관의 최신 파일은 기준일과 수치가 다를 수 있다. 이 자료로 가능한 비교는 서귀포시 내 읍면동·연도·재배유형별 생산 통계에 한정된다.

**추가 조사.** 당도·출하량 원본에서 관측 범위를 점검하여 독립 업로드용 파일을 만들었다. 가격의 경우 제주농산물수급관리센터에 9대 도매시장의 규격별 원/상자·5kg 환산 경락가격이 공개되어 있다. 도매시장, 규격, 거래일, 농가 정산비용에 따라 실수취액은 달라지므로 본 버전의 현재·미래 판매단가는 사용자가 입력한 가정으로 계산한다.
