# 기능과 수용 기준

농가가 서귀포시 생산 현황을 확인하고 보유 물량을 언제 얼마씩 출하할지 비교하는 단일 사용자 웹 서비스다.

|업무|검증 기준|
|---|---|
|자료 등록|허브 원본과 갱신 원본 보존. 업로드 CSV는 UTF-8/BOM·CP949 확인, 4 MiB·5만 행·64열 제한, 열 수와 지표 확인.|
|현황 분석|지역·연도·재배유형 합계를 실제 자료에서 계산. 당도는 관측 평균, 등급은 건수로 표시.|
|출하 계획|1kg 단위로 즉시·2회·3회·지연·최적화 5개 후보를 작성하고 오늘의 순현금 기준을 적용.|
|검증·추적|수량 보존, 기간, 순수입을 검산. 동일 데이터 버전과 조건을 DB에 보관.|
|결과 활용|추천·대안과 가정 표시, 표·차트·PDF·CSV 제공. 조건 충족 후보가 없으면 사유 표시.|
|실행 환경|Python 3.12, React/TypeScript, PostgreSQL 또는 SQLite, Docker Compose 구성.|

날짜가 부족한 실측은 해당 범위로 표시한다. 결측 수치는 합산에서 제외하고, 완전히 같은 업로드 행은 건수로 경고하되 원본 행을 보존한다. 중복이 잘못 집계될 가능성이 있으면 업로드 전에 조사 단위로 확인한다.
