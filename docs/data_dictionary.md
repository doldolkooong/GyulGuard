# 서귀포시 감귤 생산 정보

분석 단위는 연도 × 서귀포시 읍면동 × 감귤 재배유형이다. 제주데이터허브 첨부 파일(2023-04-10판)과 제공기관 갱신판(기준일 2024-05-13)을 함께 사용한다. [공공데이터포털](https://www.data.go.kr/data/15048184/fileData.do) · [제주데이터허브](https://www.jejudatahub.net/data/view/data/1313)

| 원본 열 | 형식 | 의미 |
|---|---|---|
| 연도 | 정수 | 생산 기준 연도 |
| 읍면동 | 문자열 | 서귀포시 행정구역 |
| 구분 | 범주 | 생산량(톤), 면적(ha), 농가수(호) |
| 노지온주(극조생), 노지온주(조생), 노지온주(보통) | 수치 | 노지 온주밀감 3개 분류의 해당 지표 |
| 하우스감귤(조기출하), 비가림(월동)감귤 | 수치 | 시설·수확 시기 분류의 해당 지표 |
| 만감류(시설), 만감류(노지) | 수치 | 시설 및 노지 만감류의 해당 지표 |
| 데이터기준일 | ISO 날짜 | 제공기관 갱신판에 추가된 기준일 |

| 정규화 열 | 형식 | 단위와 해석 |
|---|---|---|
| year | 정수 | 원본 연도 |
| region | 문자열 | 원본 읍면동을 양끝 공백 제거 후 사용 |
| variety | 문자열 | 원본의 일곱 재배유형 열 이름. 세부 품종명과 구별 |
| production_t | 수치 | 해당 연도 생산량, 톤 |
| area_ha | 수치 | 해당 연도 재배면적, 헥타르 |
| farm_count | 수치 | 농가수(호). 원본에 소수 값 27개가 있어 소수점을 보존한다. 여러 유형을 재배하는 농가의 중복 여부가 알려져 있지 않아 유형 합계를 고유 농가 수로 해석할 수 없다. |

농가가 입력하는 재고·출하량의 단위는 kg이다. 데이터의 생산량은 연간 통계이고 실제 출하일이나 거래량을 나타내지 않는다. 개인 농가별, 일별, 품질별, 가격별 분석에는 추가 데이터가 필요하다.

별도 제공하는 실측 당도와 신고소 출하량 CSV의 필드·단위·한계는 [추가 데이터 사전](../data/optional/README.md)에 있다.
