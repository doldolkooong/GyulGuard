# 출하 배분과 손익

**단위** 물량은 정수 kg, 단가는 원/kg, 보관비는 원/(kg·일), 출하비는 원/회다. 즉시 필요한 금액은 0일차의 출하비 차감 후 현금으로 정의한다.

**일정** 허용 일차는 0, 최대 보관 기간의 절반을 내림한 값, 최대 보관 기간이다. 중복 일차를 합치고 물량 0인 회차는 제외한다. 고정 분할안은 균등 배분하고 나머지 kg은 앞 회차부터 배분한다. 소량 또는 짧은 기간에는 서로 다른 명목 후보가 같은 일정이 될 수 있다.

**손익** 미래 단가를 입력하지 않으면 현재 단가를 유지한다. 입력하면 현재와 마지막 날 사이를 선형 보간한다. 일차 d의 물량을 q(d), 단가를 p(d), 출하비를 F, 보관비를 H라 하면 다음과 같다.

- 매출 = Σ q(d) × p(d)
- 보관비 = Σ q(d) × d × H
- 출하비 = 실제 배치 수 × F
- 예상 순수입 = 매출 − 출하비 − 보관비
- 당일 순현금 = q(0) × p(0) − 당일 배치가 있을 때의 F

**정수 모형** OR-Tools CBC가 배치별 정수 물량과 0/1 출하 여부를 결정한다. 전체 물량을 정확히 배분하고 배치별 1kg 이상일 때만 고정비를 적용한다. 당일 순현금은 입력한 최소액 이상이어야 한다.

목표는 예상 순수입에서 지연 노출과 집중도에 부여한 정책 감점을 차감한 점수의 최대화다. 지연 감점은 Σ q(d) × 현재 단가 × 위험 가중치 × d/max(1,최대일)이다. 안정형·균형형·수익형 가중치는 각각 0.12, 0.05, 0이다. 균형형은 가장 큰 배치 물량 × 현재 단가 × 0.05만큼 추가 감점해 분산을 선호한다. 가중치는 모델 설계 시 정한 선호 가정이며 실제 가격 변동률이나 비용과 구별한다. 보고서의 순수입에는 감점을 차감하지 않는다.

조건을 만족하는 후보만 순위를 매기고 동점이면 적은 실제 회차를 우선한다. 대안은 권장안과 일정이 다른 최상위 후보다. 감모·재고의 품질 변화·수요 한도·판매 상대방의 결제 지연은 모형에 포함하지 않는다.
