# 농가 시연 순서

1. 대시보드의 연도를 먼저 확인한다. 초기 생산량은 가장 최근 수록 연도인 2022년 서귀포시 기준이다. 자료 선택에서 당도·출하 관측을 별도로 열 수 있다.
2. 감귤 현황 분석에서 지역, 기간, 재배 유형을 바꾼다. 기간 전체를 선택하면 지역 차트는 여러 해의 합계를 표시한다.
3. Agent 실행 센터에서 물량과 단가를 입력한다. 예시로 보유 1,000kg, 현재 2,000원/kg, 미래 2,400원/kg, 보관비 3원/(kg·일), 출하비 20,000원/회, 10일, 오늘 필요한 순현금 400,000원을 입력할 수 있다. 예시 단가는 농가 입력 가정이다.
4. 전략 선호도를 선택하고 출하 전략 분석을 누른다. 성공 후 시나리오 비교를 연다. 즉시 1,000kg 출하안은 매출 2,000,000원에서 출하비를 차감해 당일 순현금 1,980,000원이 된다.
5. 보관 후 출하에서 오늘 현금 유입이 0원인 경우 최소 현금 조건 미충족 표시를 확인한다. 최적화안·대안의 실제 일차별 kg과 비용도 함께 살핀다.
6. 보고서 센터에서 PDF 또는 CSV를 내려받는다. 시스템 로그에서는 실행 ID, 데이터 버전, 도구 이름, 계산 결과를 비교할 수 있다.

## CSV 업로드

지원 지표는 production_t, shipment_t, brix, grade다. 최소 한 개를 포함한다. 분류에는 year, region, variety를 사용한다. 출하 일자가 date이면 일별 집계가 가능하다. 한국어 별칭은 연도/년도, 지역, 품종, 생산량(톤), 출하량(톤), 당도, 등급이다. 파일을 업로드한 후 결측·변환 오류·중복 수를 확인한다. 기본 공식 자료의 원본 다단 구조는 함께 제공한 전처리 스크립트로 변환한다.

범위에 관측값이 없으면 해당 차트가 비어 있다. 실제 출하량 보조 자료는 이틀·두 신고소에 한정된다. 자료를 바꾸어도 저장된 보고서의 버전과 계산 조건은 그대로 기록되어 있다.
