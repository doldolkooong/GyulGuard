### 전처리와 분석 흐름

1. CP949 원본을 읽고 연도·읍면동·지표를 키로 양쪽 생산 표를 대조한다. 열로 펼쳐져 있던 재배유형을 행으로 옮기고 지표를 생산량(t), 면적(ha), 농가수(호)로 나눈다. [재현 스크립트](../data/prepare_official.py)
2. [정규화 생산 표](../data/processed/official.csv)를 DB에 등록해 선택 연도·지역·유형으로 필터링한다. 대시보드는 최근 수록 연도인 2022년 서귀포시 생산량 404,233.37톤을 표시한다. [자료 사전](data_dictionary.md) · [원본 품질 대조](data_quality.md)
3. 실측 당도와 출하량은 관측 단위가 달라 독립 표로 집계한다. [보조 자료와 전처리 기준](../data/optional/README.md)
4. 가격과 비용은 농가 입력값을 사용한다. Agent는 공식 생산 통계를 보고서에 싣고, 입력한 단가와 비용으로 출하 일정별 손익·현금을 계산한다. 시연 가격은 모형 가정이며 외부 시세 피드는 사용하지 않는다.

원본 다운로드 주소는 [생산 자료 메타데이터](../data/processed/source.json) 및 [보조 자료 명세](../data/optional/README.md)에 있다. 외부 코드·서체·DB는 [오픈소스 목록](dependencies.md)에 정리했다.
